# C1测量扰动实验

## 基线与范围

使用原接触模型、5 N目标、10 mm去程与返回、8秒单程。固定PI增益、控制输出限制、接触/轨迹验收与原基线一致；物理步长1 ms，控制周期5 ms。只改变测量通道参数，不改变接触物理模型，不增加新控制器。

九工况直接复用`m1_sensor_study.cases()`，便于对照M1测量实验；本次是滑动C1工况，不能与静止M1混为同一实验。

| 工况 | 噪声标准差 / N | 偏置 / N | 延迟 / 控制步 | 低通 / Hz | 种子 |
|---|---:|---:|---:|---|---|
| zero | 0 | 0 | 0 | 关闭 | 42 |
| noise | 0.05 | 0 | 0 | 关闭 | 42 |
| bias | 0 | +0.1 | 0 | 关闭 | 42 |
| delay | 0 | 0 | 4（20 ms） | 关闭 | 42 |
| filter | 0 | 0 | 0 | 20 | 42 |
| combo42/43/44 | 0.05 | 0 | 2（10 ms） | 20 | 42/43/44 |
| stress | 0 | 0 | 100（500 ms） | 关闭 | 42 |

这些是仿真假设，不是实测传感器规格，也不表示允许的硬件延迟。低通还引入相位滞后，不能只用队列步数代表总延迟。

## 运行与接口

```powershell
python -m experiments.c1_sensor_study
python -m experiments.c1_sensor_study --output results/CS
python -m pytest tests/test_c1_sensor_study.py -q
python -m pytest tests -q --basetemp=t_all
```

所有命令从仓库根目录执行。已有Python环境可直接使用，无需重新下载模型。默认无窗口运行，每次新建`results/CS/run_XXX/`；九个子目录`c0`至`c8`对应表中顺序，每个子目录保存独立C1运行。不得用pytest临时目录长期存实验，pytest会清理该目录。

| 函数/输出 | 含义 |
|---|---|
| `c1_sensor_study.run(output_root=None)` | 返回批量结果目录，逐组调用既有`c1_wipe.run` |
| `analyze(frame, config)` | 使用物理日志，只对完整运动段计算RMSE、实际往返及接触丢失 |
| `study_config.json` | 展开的基线、每组测量参数、批量入口源码SHA256 |
| `comparison.csv` | 各组实际任务判定、失败原因、指标及数据子目录 |
| `study_summary.json` | 完成记录数、任务通过数、完整运动段数与三种子组合统计 |
| `c1_sensor_study.png` | 真实力误差、完整运动段RMSE与接触丢失时间 |
| `cN/run_001/` | 真实力、控制命令、关节反馈、原始接触、场景、摘要、日志及已有曲线 |

## 判定和指标

`任务验收通过`完全使用原C1最终摘要，包含基础限制、连续接触与实际往返要求。**原C1没有运动段力RMSE通过门槛**，所以任务PASS不代表已达到某个力跟踪精度；本实验不临时增加或放宽阈值。峰值偏差是运动段最大真实力减5 N的非负部分，不混入接近阶段。

运动段为`[10, 26)`秒，完整时应有16000个物理样本，并有26秒端点用于往返评价。接触丢失以`tool_contact_count == 0`判定，每个样本代表1 ms；累计时间为样本数乘物理步长，最长时间按连续零接触区间统计。它是离散采样指标，不声称定位到亚毫秒。真实力由`contact_force.csv`取得，控制器仍使用`control.csv`的滤波后测量。

若提前终止导致运动段不完整，只记录已有运动样本数和完整性，不生成完整段RMSE、往返与丢失时间；图中标记“未完整”，不填成零。若运动段已结束、末态检查随后失败，可以保留完整运动段指标，但总任务仍FAIL。组合统计明确列出三个种子的运行数、完整段数和任务通过数；均值/样本标准差仅针对有完整运动段的运行，不能隐去分母。

批量入口捕获已有失败摘要的验收异常以继续后续工况，不删除或改写原始FAIL；没有实际失败摘要或摘要仍为PASS的其他异常会继续抛出。批量命令正常结束仅表示完成记录，必须查看各组判定。

## Debug与适用边界

失败工况应保存配置、原始CSV、错误时刻/原因、曲线、控制输入和测量时间戳。排查时先对齐真值与测量，再看PI限幅、接触丢失及末态检查；不能只根据平滑曲线判断改善。偏置可能在测量看似贴近5 N时留下真实力误差。

这里只验证固定PI、单一目标和原接触模型的少量工况。没有验证任意噪声、全部延迟、真实传感器或真机；三种子结果也不是统计安全保证。在线模糊PI已有独立实验，本入口不把固定PI结果当作模糊控制效果。
