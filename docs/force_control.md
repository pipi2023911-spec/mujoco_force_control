# 力控实验方案

## 开发顺序与验收等级

最小功能 → 修改代码 → 运行 → 记录数据 → 分析问题 → 补充必要理论 → 再验证。保留现有接口、限幅和失败留证，不先建立大型控制框架。

| 阶段 | 交付与验收 |
|---|---|
| 固定 PI 基线 | 核对真实接触力来源、方向、单位、周期及接触接管；保存 Baseline/PI 同初态对照 |
| 测量通道 | 默认精确直通；独立验证偏置、噪声、延迟和低通；控制器用测量，评价用真值 |
| 初始增益依据 | 使用 M0-04 局部位移—力数据估算有效刚度，记录拟合区间和残差 |
| 模糊自适应 PI | 明确误差/误差变化率、隶属函数、规则表和增益上下界，逐周期实际调整 Kp/Ki |
| 同条件对照 | 固定 PI/模糊 PI 共用场景、初态、目标、测量配置、随机种子和验收定义 |
| 接触与扰动鲁棒性 | 先单因素，再少量组合、多随机种子、不同接触软硬条件，报告失败 |

`ForcePI` 保留固定增益，`FuzzyAdaptivePI` 已实现在线规则与实际 Kp/Ki 更新。测量通道本身仍不等于自适应；模糊算法、状态处理与对照入口见[在线模糊 PI](fuzzy_pi.md)。接触参数变化尚未完成有效刚度标定。

## 基线与传感器实验

M1 默认 5 N 目标，8 秒接管，12 秒结束。固定位置 Baseline 与 PI 分别从 home 状态运行；接管前不施加力修正，接管时要求持续接触。PI 保留积分贡献、位移修正和修正速度限制。

1. 省略传感器字段，重跑默认对照，核对测量值与控制时刻真值逐值一致。
2. 仅启用白噪声，记录种子；再分别测偏置、整数周期延迟和低通。
3. 对可稳定运行的条件进行少量组合。低通抑制噪声的同时引入相位滞后，不能默认滤波总能改善闭环。
4. 同条件做多种子重复，保存通过、失败与超限日志。不要预先规定某一档必须振荡，也不要调整阈值掩盖失败。

`configs/sensor_example.json` 是组合扰动运行示例。单组接入测试使用更小扰动验证数据链，其通过不能证明示例及任意参数都稳定。任何传感器值都应标为仿真假设，直到有独立硬件标定数据。

## 增益设计与在线调整

M0-04 提供不同参考压入量对应的接触力。应先检查稳态、接触状态、拟合残差和重复性，再把局部斜率作为有效刚度估计。参考位移到力的斜率包含位置内环柔顺性，不等于材料刚度。

在快内环、局部准静态线性接触、无明显延迟且未饱和的假设下，可用近似关系为 PI 选初值；不能将该近似作为全工况稳定性证明。MuJoCo `solref` 是接触求解参数，不能直接标成已经标定的 N/m。不同接触参数应先做位移—力辨识。

模糊 PI 的最小实现应明确：输入误差及经过必要处理的误差变化率，归一化范围，隶属函数，规则输出，增益范围和更新方式。增益更新进入实际控制周期，并记录实际生效的 Kp/Ki。处理积分状态衔接，继续保留抗积分饱和和输出限制；无需增加无关状态机。

## 评价定义

主要性能使用 `contact_force.csv` 的真实法向力。另列测量误差，不能用滤波后的平滑信号替代真实性能。

- 现有 M1 “末秒 RMSE”：最后 `hold_metrics_window_s` 窗口内目标减真实力的均方根；它不是整个接管阶段的 RMSE。
- 现有稳定时间：从接管开始计时，最后一次越出 `tracking_tolerance_n` 后持续到结束，并至少满足 `settling_min_duration_s`；结束前仍越带则无稳定时间。
- 接管后峰值包含接管初始力，不能把初始 Baseline 偏差全部解释成控制器引起的超调。后续对照需分别报告初始条件、峰值、正向超调及目标阶跃响应。
- 模糊对照还需统一统计整个控制窗口 RMSE、末段误差、超调量、接触丢失、限幅占比和失败数，并展示 Kp/Ki 实际曲线。

配置、随机种子、代码版本、源码/模型摘要、原始数据、统计定义和曲线需一起保存。不要承诺模糊 PI 在所有条件下优于固定 PI。

## 后续支线

导纳目标力扩展保留为主线后的独立 M2b：默认兼容原 M2，明确力方向、接触接管和限幅，单独定义力跟踪指标。K=0 时趋近零稳态误差需要可达稳定平衡且未饱和；理想弹簧数值结果不能替代 Panda 接触仿真。
