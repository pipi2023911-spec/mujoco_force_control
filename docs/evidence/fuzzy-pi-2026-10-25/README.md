# 在线模糊 PI 实现与闭环验收

日期：2026-10-25。使用现有 Python 3.12.14、MuJoCo 3.3.7、NumPy 2.2.6、Pandas 2.2.3、Matplotlib 3.10.3、pytest 8.3.5；无新增依赖。

**结论：规则型在线模糊自适应 PI 已实现并实际运行，六组模糊实验的 Kp/Ki 均在线变化并参与输出；固定/模糊共 12 次物理仿真均通过原 M1 阈值。** 没有证明全工况稳定、最优整定或全面优于固定 PI。

## 实际修改与运行

核心为 `controllers/fuzzy_pi.py`；M1 的反馈参考按 `pi_algorithm` 选择控制器，默认保持 fixed，CLI 支持 `--algorithm fuzzy`。`experiments/m1_fuzzy_comparison.py` 只组织同条件对照，未重建控制框架或改变物理检查。

```powershell
python -m experiments.m1_fuzzy_comparison
python -m experiments.m1_force_pi --mode pi --algorithm fuzzy --sensor-config configs/sensor_example.json
python -m pytest tests -q --basetemp=t_all
```

上面命令均已实际运行。完整测试 **64 PASS、1 FAIL**；唯一 FAIL 为在未修改提交中已经复现的 C1 连续接触，不属于新模糊 PI 实验。新增模糊测试 10 项均通过，其中 1 项实际推进 Panda 仿真；未调整或跳过原有断言。

## 六条件配对结果

同一目标 5 N、同一初态、8 秒接管、12 秒结束；配对的基准增益、传感器、种子、限幅与原 M1 验收阈值相同。每种算法独立复位运行，接管前真实力逐值一致。下表误差为最后 1 秒真实力 RMSE。

| 条件 | 固定 PI（N） | 模糊 PI（N） | 固定/模糊稳定时间（s） |
|---|---:|---:|---|
| 无扰动 | 0.003493340 | 0.001228939 | 1.221 / 1.166 |
| 组合扰动，种子 42 | 0.006420872 | 0.006715175 | 1.246 / 1.229 |
| 组合扰动，种子 43 | 0.006148101 | 0.005966257 | 1.141 / 1.169 |
| 组合扰动，种子 44 | 0.006603393 | 0.006368702 | 1.196 / 1.183 |
| contact_solref=[0.03,1] | 0.003045681 | 0.000661325 | 1.101 / 1.076 |
| contact_solref=[0.01,1] | 0.002588394 | 0.000510308 | 1.276 / 1.261 |

组合扰动为白噪声标准差 0.05 N、偏置 0、延迟 10 ms、低通 20 Hz。三个种子末秒 RMSE 均值 ± 样本标准差：固定 `0.006390789 ± 0.000229132 N`，模糊 `0.006350045 ± 0.000374808 N`。均值差很小，模糊结果离散性更大，不应据此宣布噪声鲁棒性优越。

种子 42 下，模糊末秒 RMSE 比固定高约 4.6%；种子 43 下稳定时间略长；contact_solref=[0.01,1] 时模糊接管全程 RMSE 为 0.280416 N，固定为 0.279701 N，尽管末秒误差更低。所有不利结果完整保留，不以单一较好指标覆盖其他指标。

改变 solref 的时间常数并未标定有效刚度，不能把两组数值写成已知 N/m 的不同材料。三随机种子、一个目标、有限接触参数不足以证明普适稳定性。

## 在线增益的直接证据

无扰动模糊 PI 接管后的实际 Kp 范围为约 `[1.99927e-5, 2.04486e-5] m/N`，Ki 为 `[2.96391e-4, 3.29998e-4] m/(N*s)`。每组 800 个控制激活样本都有实际增益记录。默认固定 PI 的 Kp/Ki 为常值。

逐行核对 `pi_p_m = pi_kp_m_per_n * force_error_n`，并检查积分贡献、位移及速度限制；所有对照均通过。相同种子的配对测量噪声序列亦逐值核对（允许浮点计算容差），不是给两种控制器使用不同随机噪声。

增益上下界、误差变化率滤波、隶属函数、9 条规则、增益平滑、Kp 变化的积分补偿，以及 Ki 不重缩放历史积分的原因见[算法说明](../../fuzzy_pi.md)。锁定增益上下界的数值测试逐值复现固定 PI，证明接口与核心 PI 限制兼容。
