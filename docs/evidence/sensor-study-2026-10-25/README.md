# 固定 PI 测量扰动实验

日期：2026-10-25。命令：`python -m experiments.m1_sensor_study`。解释器复用现有 Python 3.12.14 / MuJoCo 3.3.7 环境，没有安装新依赖。

固定目标 5 N、8 秒接管、12 秒结束、控制周期 5 ms，全部工况使用相同模型、PI 增益、限幅、初态和原 M1 验收阈值。随机种子只在组合重复中变化；单因素结果只代表单组。

## 实际结果

| 工况 | 测量参数 | 末秒真实力 RMSE（N） | 稳定时间（s） | 原 M1 判定 |
|---|---|---:|---:|---|
| 无扰动 | 默认直通 | 0.003493 | 1.221 | PASS |
| 仅噪声 | 标准差 0.05 N，种子 42 | 0.014295 | 1.787 | PASS |
| 仅偏置 | +0.1 N | 0.099419 | 2.992 | PASS |
| 仅延迟 | 4 步，20 ms | 0.001961 | 1.166 | PASS |
| 仅低通 | 20 Hz | 0.003031 | 1.211 | PASS |
| 组合，种子 42 | 噪声 0.05 N、延迟 10 ms、低通 20 Hz | 0.006421 | 1.246 | PASS |
| 组合，种子 43 | 同上 | 0.006148 | 1.141 | PASS |
| 组合，种子 44 | 同上 | 0.006603 | 1.196 | PASS |
| 大延迟压力工况 | 100 步，500 ms | 0.044251 | 2.261 | PASS |

所有工况完整运行，均满足既有 M1 阈值；没有为了获得失败而改阈值。三种子组合末秒 RMSE 均值为 0.006390789 N，样本标准差（ddof=1）为 0.000229132 N，仅 3 次重复，不能当作充分的概率稳定性证据。

## 解释与边界

- +0.1 N 偏置下，真实末秒平均力为 4.900581 N，测量力接近目标而真值仍偏离。该工况虽 PASS，但接近 0.1 N 的现有误差阈值；通过不表示偏置被消除。
- 500 ms 延迟在这一个工况中通过，稳定时间由 1.221 秒增加到 2.261 秒。不能把 500 ms 写成安全延迟上限或全部工况的延迟裕度。
- 20 ms 延迟工况末秒 RMSE 较小，只是这套参数和统计窗口的结果，不证明增加延迟能普遍改善控制。
- “正向峰值偏差”包含接管时已经存在的初始偏差，当前各组接管初始力约 5.96495 N。它不是独立目标阶跃试验得到的控制超调。
- 全程 RMSE 从接管时刻开始，和末秒 RMSE 分开记录；性能按真实力计算，不使用滤波曲线替代。

没有实现或验证模糊 PI，没有更换接触参数或做有效刚度标定，没有真实传感器或真机。下一步应在这套记录接口上加入在线增益算法，再做同条件对照。

## 回归与失败保留

完整原有回归命令 `python -m pytest tests -q --basetemp=t_all`：52 项通过，1 项既有 C1 连续接触失败。新增统计测试随后单独执行 `python -m pytest tests/test_sensor_study.py -q`：2 项通过，验证提前终止不产生伪造末秒指标，未达标轨迹仍可统计且原验收继续拒绝。

两次命令合计覆盖当前 55 项测试，54 PASS、1 FAIL，不能称为全部测试通过。C1 失败已在未修改提交中复现，保持原断言与原阈值，没有新增失败、跳过或放宽检查。

批量入口遇到实验 `ValueError` 会保留原始失败并继续后续工况，汇总中的通过数才是控制验收结果；命令退出正常只表示记录流程完成。未捕获的程序/文件错误仍会停止批量流程。
